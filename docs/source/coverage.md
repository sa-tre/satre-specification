# Coverage & Mappings

This page lets you explore how SATRE requirements map to external **standards** (such as
ISO 27001 or the NHS DSPT) and to **patterns** and **products** that have been documented
or built to help meet them.

Select one or more tags below. Requirements matched by your selection are shown as
**covered**; the rest are shown as **not covered**, so you can quickly see where a set of
standards or tools leaves gaps. You can export the current view as CSV.

:::{note}
Tag data is community-contributed and informational. It does not imply formal
accreditation or endorsement. Mappings are a starting point, not a substitute for a full
evaluation.
:::
